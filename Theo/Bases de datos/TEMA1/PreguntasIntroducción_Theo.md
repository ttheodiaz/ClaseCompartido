Qüestionari inicial
1. Què és una base de dades ( BD )?
Una Base de Datos es un depósito de información digital.
2. I quina relació hi ha entre una BD i un sistema gestor de base de dades ( SGBD )?
El gestor es el que modifica, elimina o añade la información de la base de datos.
3. Pots citar tres SGBD ?
MySQL, PostgreSQL y no sé más.
4. Per què serveix el diccionari de dades d'una BD ?
No lo sé exactamente.
5. Quina relació hi ha entre la integritat i la redundància de les dades?
La integridad verifica que los datos sean correctos y la redundancia no sé que es en un contexto de bases de datos.
6. Saps què signifiquen les sigles ACID?
No.
7. Podem emmagatzemar totes les dades personals dels usuaris de les nostres aplicacions?
